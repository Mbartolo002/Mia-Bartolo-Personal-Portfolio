# Personal Website (Vite + React)

This repository is a minimal Vite + React single-page personal website template.

Features
- Homepage with introduction
- About, Experience, Projects, Contact sections
- Responsive layout
- Theme toggle (light/dark)
- Basic SEO meta tags

Run locally

1. Install dependencies:

```bash
cd "~/react and vite website"
npm install
```

2. Start dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```
